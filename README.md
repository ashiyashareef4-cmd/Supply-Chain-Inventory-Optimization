# Supply Chain & Inventory Optimization Dashboard

## Project Overview
An interactive Power BI dashboard developed to analyze supply chain operations, inventory performance, sales, and delivery efficiency.

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Features
- Sales and Profit Analysis
- Inventory and Stock Performance
- Supplier Performance Analysis
- Logistics and Delivery Analysis
- Interactive Slicers and Page Navigation

## Key Skills
Data Cleaning | Data Modeling | DAX | Data Visualization | Business Analysis
